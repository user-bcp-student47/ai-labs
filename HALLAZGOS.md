### Contrato observado antes de implementación

`docs/ENDPOINTS.md` no existe. Esta sección conserva el comportamiento registrado durante discovery antes de corregir el código; las referencias indican las líneas de esa revisión, no constituyen un contrato acordado.

- Ruta `POST /auth/login`, con solicitud JSON recibida como `LoginRequest`, cuyos campos incluyen `username`, `password` y `client`: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:15,22-24`; `auth/src/main/java/com/bcp/workshop/auth/LoginRequest.java:3-6`.
- Solicitud nula, `username` vacío/nulo o `password` vacío/nulo producen HTTP 400: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:26-33`.
- El recurso envía `username` y `password` al método de persistencia: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:35`.
- Si no obtiene usuario, responde HTTP 401 con un mensaje que incluye el nombre recibido; si lo obtiene, responde HTTP 200 con `token`, `expiresIn`, `user` y `debug`: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:37-49`.
- Las excepciones capturadas en el recurso producen HTTP 500 con `message` y `exception`: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:54-58`.
- La base por defecto se configura como `jdbc:sqlite:./data/workshop.db`, con posibilidad de reemplazo mediante `AUTH_DB_URL`: `auth/src/main/java/com/bcp/workshop/auth/LegacyDatabase.java:15`. La inicialización crea la tabla e inserta usuarios de taller: `auth/src/main/java/com/bcp/workshop/auth/LegacyDatabase.java:21-24`.

### Comportamiento actual verificado

- La ruta continúa siendo `POST /auth/login`; la validación vacía produce 400, credenciales inválidas 401 y login válido 200: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:16,26-46`; comprobado en `auth/src/test/java/com/bcp/workshop/auth/AuthResourceTest.java:41-115`.
- La respuesta de éxito conserva `token`, `expiresIn`, `user` y `debug`; el token ahora es JWT HS256 con claims y expiración verificados: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:67-80`; `auth/src/main/java/com/bcp/workshop/auth/TokenService.java:40-85`.
- El error mantiene HTTP 500, pero devuelve un mensaje genérico sin `exception`: `auth/src/main/java/com/bcp/workshop/auth/AuthResource.java:49-54`; prueba en `auth/src/test/java/com/bcp/workshop/auth/AuthResourceTest.java:161`.
- La base local de prueba usa una copia bajo `auth/target/`; la migración del esquema antiguo se verificó sobre esa copia, no sobre `auth/data/workshop.db`: `auth/src/main/resources/application.properties:10-11`; `auth/src/test/java/com/bcp/workshop/auth/AuthResourceTest.java:173-204`.
- El perfil `%prod` deshabilita el bootstrap TRAINER y el repositorio también impide consultar un registro preexistente con ese nombre. La prueba HTTP verifica 401 sin token, mientras pruebas de repositorio cubren la configuración efectiva del perfil y la base existente: `auth/src/main/resources/application.properties:11-12`; `auth/src/main/java/com/bcp/workshop/auth/UserRepository.java:62-64,150-157`; `auth/src/test/java/com/bcp/workshop/auth/AuthResourceTest.java:79-95`; `auth/src/test/java/com/bcp/workshop/auth/UserRepositoryTest.java:24-72`.

### Verificación pendiente

- El `mvn verify` desde `auth/` pasó 19 pruebas; JaCoCo midió 92.72% (191/206 líneas) en las clases de producción modificadas. El detalle por comando e ID está en `PLAN.md`.
- CodeQL y Dependency Review remotos no se ejecutaron; tampoco se ejecutó un escáner del árbol transitivo completo.
- No se inspeccionaron consumidores fuera de `auth/`; queda por confirmar que ninguno dependa del formato Base64 interno anterior. El campo JSON `token` y la forma de la respuesta se conservaron.
- Para ejecutar auth fuera del perfil de prueba se debe proporcionar `AUTH_TOKEN_SECRET` con al menos 32 bytes. En despliegue se debe configurar `AUTH_CORS_ORIGINS` con los orígenes reales permitidos; no se confirmó un origen de despliegue en este alcance.
- H-AUTH-09 sigue como candidato: la cuenta fija STUDENT se continúa sembrando en producción por decisión de alcance; se requiere revisión independiente.
